# Profit Paradox character art

The six original character PNGs came from the user's Profit Paradox handoff ZIP.

`ceo_thinking_v2.png` and `ceo_loss_v2.png` were edited with the built-in OpenAI image generation tool from `ceo_neutral.png`. `sara_thinking_v2.png` was edited from `sara_neutral.png`, and `sara_aha_v2.png` from `sara_explaining.png`. The edit prompts required the same exaggerated 2D cartoon proportions, facial features, costume, colors and outline style, with only the expression and pose changed. Each output was checked for a transparent corner pixel and viewed at full resolution before import. The first alternate visual direction generated during exploration was rejected and is not included in this project.

The handoff ZIP's `reference/visual_style_reference.png` informed the code-native rounded buttons, bold outlines, shadows and UI accents. The flattened reference board itself is not a gameplay asset; its sample charts and labels are not used as game data.
