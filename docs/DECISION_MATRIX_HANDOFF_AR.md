# تسليم دمج مصفوفة القرار

## حالة الدمج — 2026-10-25

أُضيفت لعبة «مصفوفة القرار — أول يوم في الشركة» كلعبة خامسة من حزمة ZIP المعتمدة، تحت المسار المحمي `/games/decision-matrix`. تُعرض ملفات `dist/` التشغيلية كما هي في iframe مستقل من `public/decision-matrix/` مع الحفاظ على اتجاه RTL وملفات CSS ومسارات الأصول والصوت.

تستخدم اللعبة معرّف سياق iframe المأخوذ من حساب اللاعب لإنشاء مفاتيح مستقلة للحفظ والتفضيلات في `localStorage`. بذلك لا يقرأ حساب آخر على الجهاز تقدم هذا الحساب. الحفظ محلي في المتصفح فقط، ولا يتزامن بين الأجهزة أو المتصفحات. لا يلزم ترحيل قاعدة بيانات.

المسار ملفوف بـ`RequireProfile` مثل بقية الألعاب، وزر الرجوع إلى `/app` موجود في شريط مستقل أعلى مساحة اللعب حتى لا يحجب أي تحكم. أُضيفت بطاقة اللعبة خامسة بعد البطاقات الأربع الموجودة.

## حدود الوصول والأصول

لا توجد قيود اشتراك جديدة؛ تظل اللعبة متاحة للمستخدم المسجل دخوله الذي أكمل ملفه، وفق حدود الوصول الحالية للمنصة. حماية React لا تحمي روابط الملفات الثابتة تحت `/decision-matrix/`، ويمكن طلب HTML وJavaScript والصور والصوت مباشرة. لا تُعامل هذه الملفات كأسرار أو كحد وصول تجاري؛ يلزم تخطيط منفصل لحماية الأصول إذا أصبحت entitlement شرطًا مستقبلًا.

## التحقق

- حزمة المصدر: شُغّل `node build-deliverables.cjs` ثم `npm test` من جذر الحزمة. نجحت اختبارات الحلول الفريدة للألغاز الثلاثة، الحسابات والانتقالات، الصوت، تسلسل الاجتماع، المشهد الثابت، واللوحات.
- تحقق المنصة: `tests/decision-matrix-integration.test.mjs` يختبر مساحة التخزين لمستخدمين، وجود خمس بطاقات، حماية المسار بمتطلبات الملف المكتمل، وتمرير معرّف الحساب وزر الرجوع للـiframe.
- المتصفح الفعلي عبر خادم Vite المحلي: ظهرت شاشة البداية، واكتمل الحوار الافتتاحي، وفُتح تقرير CRM وملفات الأدلة، ثم ظهرت مساحة التحليل وشبكة اللغز الأول. استجابت ملفات الأصول الـ22 جميعها بـHTTP 200. لم تُختبر مراحل الألغاز الثلاث حتى النتيجة النهائية يدويًا؛ اختبارات حزمة المصدر تحققت من الحلول وقواعد الألغاز الثلاثة.
- فحوص المنصة: تطبيقا TypeScript (app وnode) والبناء الإنتاجي نجحت. يُظهر البناء تحذير حجم chunk موجودًا في التطبيق، ولا يمنع إنتاج الملفات.
- تعذر قياس واجهة المتصفح يدويًا عند 390×844 و360×740 لأن واجهة المتصفح المتاحة لا تعرض تغييرًا لمقاس viewport. لا يُدعى اجتياز هذين المقاسين. كذلك لم يُسجّل دخول حقيقي أو يُستخدم backend حي لاختبار تحويل المستخدم غير المسجل؛ حماية `RequireProfile` مفحوصة في تسجيل المسار واختبار التكامل.

## إعادة الاختبار

من جذر المستودع:

```sh
node --test tests/decision-matrix-integration.test.mjs
npx tsc -p tsconfig.app.json --noEmit
npx tsc -p tsconfig.node.json --noEmit
npm run build
```
